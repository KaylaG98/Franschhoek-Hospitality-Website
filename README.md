# Franschhoek Hospitality Academy website

Static website for the Franschhoek Hospitality Academy & Learning Centre, hosted on GitHub Pages.

## How it is organised

- `src/pages/` – the content of each page (edit these)
- `src/footer.html` – the shared footer
- `build.py` – adds the shared header, footer and page titles to every page. Run `python3 build.py` after editing anything in `src/`.
- `css/site.css` – all styles (colours and fonts are set at the top)
- `js/site.js` – mobile menu, donation box and video buttons
- The `.html` files in the root are the built pages that GitHub Pages serves.
